🔄 自动更新机制

GitHub Actions 每天 04:00 UTC（北京时间中午 12:00 / 美西前一晚 9:00）运行，刷新时间戳并触发 Pages 重建。主 Agent 的 cron baby-site-daily-update 会在 22:00 PT 推送真实的成长内容。

文件：last-updated.txt · 工作流：.github/workflows/daily-refresh.yml · 支持手动触发 workflow_dispatch
